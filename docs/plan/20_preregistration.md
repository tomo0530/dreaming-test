## 1. 主仮説（1 つ）

> H1: SchemaDrift-SQL の実行一致率において、A4（transcript で裏付けを取る Dreaming）は A1（transcript を読める Rolling Summary、同一モデル・同一予算）を上回る。

- 推定量: Δ = mean_s [acc_s(A4) − acc_s(A1)]（s はストリーム、acc は当該ストリームの全問正答率）。
- 区間: ストリームを再標本化単位とする paired bootstrap、10,000 回、パーセンタイル法 95% CI。bootstrap の乱数 seed は 20261110。
- 判定: CI 下限 > 0 → H1 を支持。CI が 0 を含む → 「優位を示せない」。CI 上限 < 0 → 「A1 が上回った」。
- 実務上の目安: Δ ≥ +0.05。目安に届くかは点推定で併記するが、判定には使わない。
- 主張の範囲: A4 と A1 は記憶システム全体として比較する。A4 はオンラインでメモを書けるが A1 は書けないため、Δ にはセッション内のメモ書きの効果も含まれる。オフライン処理は合計ターン数・累計入力上限・`reasoning_effort` を揃えている。
