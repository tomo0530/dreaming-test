## Notes the agent wrote after each question

After every question the agent writes one note under `memory/notes/` on what it found out about the database. A note is the agent's own account, written without knowing whether its answer was right: it is an unverified claim, never evidence, however specific or confident it sounds, and even where it says that a query confirmed it. Take a statement from a note into memory only after a `query` result or an `EVENT feedback:` record in the transcripts backs it, and tag it with the session of that evidence. A statement that the evidence contradicts was wrong: correct it from the evidence and keep none of its wording. A statement that no evidence settles stays an unverified claim.
